# BioDataLab.id

### Learn data science through life science problems.

* BioDataLab.id is a learning platform for people who want to develop data science skills through biological and life science problems.
* We create hands-on learning materials using real biological datasets, guided analysis, and practical Python workflows.
* The learning path progresses from foundational data analysis to more advanced applications in biomedical data science, computational biology, and other life science domains.


## Learning Path

BioDataLab.id follows a progressive learning path:

**Starter** → **Beginner** → **Specialization** → **Capstone / Portfolio**


| Level | Focus | Goal |
|---|---|---|
| **Starter** | Follow and modify | Understand biological data analysis |
| **Beginner** | Analyze with guidance | Perform small biological data analyses |
| **Specialization** | Apply to a biological domain | Work with domain specific problems |
| **Capstone** | Build a project | Demonstrate practical skills |

## Who Is It For?

BioDataLab.id is designed for learners from life science backgrounds, including:

- Biology
- Microbiology
- Biotechnology
- Biomedicine
- Agriculture
- Fisheries and Aquaculture
- Other life science fields

It is also suitable for beginners transitioning into biological data science.
